Services & Devices

Enable/disable services and choose CPU or GPU per service. Changes apply immediately on Save. iEach service runs independently. Unchecking a service unloads it and frees GPU/RAM immediately. Checking a service loads it on Save. Device 'auto' uses GPU if available, falls back to CPU.
ServiceEnabledDevice
STT iSpeech-to-Text: Transcribes audio to text using Whisper models. Supports sherpa-onnx (fast, cross-platform) or faster-whisper (CTranslate2) engines.
TTS iText-to-Speech: Converts text to spoken audio using Piper ONNX voices. Runs on CPU only — no GPU contention. Supports response caching for instant repeat playback.CPU only (Piper ONNX)
LLM iLarge Language Model: Runs a local AI model for chat responses via llama.cpp GGUF. Most GPU-intensive service.
Vision iImage captioning: Analyzes images and generates text descriptions. Can use a dedicated model (BLIP, Moondream, etc.) or your LLM if it supports vision.
ImageGen iImage generation: Creates images from text prompts using Stable Diffusion. Very GPU-intensive — requires significant VRAM.
MusicGen iMusic generation: Creates music audio from text prompts using Facebook MusicGen. GPU-recommended for reasonable generation times.
Embeddings iText embeddings: Converts text into numerical vectors for semantic search. Used by TARS memory system (RAG). Lightweight — works well on CPU.
